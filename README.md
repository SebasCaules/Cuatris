# Cuatris

Planificador de cursada para Ingeniería en Informática del ITBA (plan S10-Rev23): acomoda
materias en los cuatrimestres futuros y muestra correlativas, choques de horario y carga.

Sitio: https://sebascaules.github.io/Cuatris/ · Sin servidor: una SPA que lee JSON versionados
en este repositorio, mantenidos por una CLI en Python y validados en cada PR.

- `CLAUDE.md` — guía del proyecto (decisiones, reglas, mapa de documentos).
- `entregables/` — brief, planes de backend y de sprints, diseño importado.
- `docs/` — contrato de datos, plan de estudios, scraping del SGA (se completan por sprint).

En construcción: Sprint 1 (MVP). Ver `entregables/sprint-1/EXEC_STATE.md`.
